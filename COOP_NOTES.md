# Как используется подход Co-op Anything

Источник: https://github.com/cranebeaker/coop-anything

`coop-anything` — проект с инструкциями для ИИ-агентов и инструментами исследования, проверки, синхронизации и сборки кооперативных модов. Это **не JavaScript-библиотека, которую можно просто импортировать в GitHub Pages**, и не встроенный публичный сервис игровых комнат.

В данной браузерной игре реализована отдельная WebRTC-схема, соответствующая базовым принципам сетевой синхронизации:

- Host authority: только хозяин вычисляет урон, события и победу.
- Guest input: клиент второго игрока отправляет нормализованные команды управления (`left`, `right`, `jump`, `block`, `punch` и др.).
- State replication: хозяин регулярно отправляет фактическое состояние бойцов, арены, эффектов и таймера.
- Recovery: при потере канала игра останавливается, игрокам показывается состояние соединения.
- Browser signaling: PeerJS Cloud используется только для установления WebRTC-канала; сам GitHub Pages не выступает как игровой сервер.

Для готового публичного сервиса с устойчивой игрой через разные сети стоит добавить собственную службу сигнализации, TURN-relay, корректную интерполяцию, reconnect/resume, проверки версий клиентского протокола и E2E-тесты на разных устройствах.
